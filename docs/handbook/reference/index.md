# Reference

This section collects the materials that support the narrative chapters
of the handbook: exhaustive API documentation, a catalog of all bundled
features, a glossary of terminology, and troubleshooting guidance.

## Contents

**[API Reference](api_reference.md)** --- Complete documentation of every
public module, class, function, and protocol in the `distfeat` package.

**[Feature Catalog](feature_catalog.md)** --- A tabular listing of all
features defined in each bundled system (IPA, Tresoldi, Distinctive,
P-base variants), together with their value domains and descriptions.

**[Glossary](glossary.md)** --- Definitions of phonological and
computational terms used throughout the handbook, from *distinctive
feature* to *feature geometry* to *segment distance*.

**[Troubleshooting](troubleshooting.md)** --- Solutions to common
installation issues, import errors, and dataset-loading problems.
