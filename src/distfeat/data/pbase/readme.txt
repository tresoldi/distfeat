PBase data as of October 2, 2022

pb_languages.csv        

	lists all the languages, with inventory, genealogy, location, old pbase language code, and reference

pb_patterns.csv

	lists all of the alternations and distributional restrictions

seg_convert.csv

	provides phonetic descriptions for all IPA transcriptions used in PBase

ipa2allfeatures.csv

	provides distinctive feature values for all IPA transcriptions used in PBase (Preliminaries, SPE, UFT, Halle & Clements)
	
grouping-diagnosis.csv

	sound pattern labels assigned by Brohan & Mielke (2018)
